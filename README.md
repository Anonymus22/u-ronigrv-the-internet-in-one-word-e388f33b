# The Internet in One Word

**Doomscrolling**

The whole internet, in a single word: *Doomscrolling* — the endless, joyless, can't-look-away scroll through bad news, hot takes, and one more video that somehow eats the entire evening. Funny because it's true, and true because we've all done it tonight.
